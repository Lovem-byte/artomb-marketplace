# artomb-branding

A Claude plugin that applies ARTOMB Recruitment's official brand system (colors, fonts, logo, layout patterns) to any deck, document, PDF, form, or spreadsheet Claude creates.

## What's inside

- `skills/artomb-branding/SKILL.md` — the skill instructions Claude follows
- `assets/ARTOMB_Brand_Guide.md` — the full brand guide (colors, fonts, typographic scale, logo rules, layout patterns)
- `assets/ARTOMB_PowerPoint_Template.pptx` — the official 11-layout master PowerPoint template
- `assets/logo-icon-purple.png`, `assets/logo-icon-white.png`, `assets/logo-lockup-white.png` — approved logo files

## Brand summary

- **Colors:** Deep Purple `#1F0248`, Secondary Purple `#3B1C68`, Accent Gold `#D5A546`, Ink `#242330`, Muted Gray-Purple `#6B6874`, Light Tint `#F5F2F8`, White `#FFFFFF`
- **Fonts:** Georgia Bold for headings, Arial for body copy
- **Tagline:** "Building Careers. Empowering Businesses."

See the SKILL.md and brand guide for full detail.
