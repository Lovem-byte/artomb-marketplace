# ARTOMB Marketplace

A private Claude Code / Claude Cowork plugin marketplace for ARTOMB Recruitment.

## Plugins

### artomb-branding

Applies ARTOMB Recruitment's official colors, fonts, logo, and layout style to any deck, document, PDF, form, or spreadsheet Claude creates. See [`plugins/artomb-branding`](plugins/artomb-branding) for details, including the bundled brand guide, master PowerPoint template, and logo files.

## Adding this marketplace

In Claude Code or Claude Cowork, run:

```
/plugin marketplace add Lovem-byte/artomb-marketplace
```

## Installing the plugin

```
/plugin install artomb-branding@artomb-marketplace
```
